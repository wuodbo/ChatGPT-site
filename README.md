# SweetMoment — HTML / CSS / JavaScript

## Запуск
1. Распакуйте архив.
2. Откройте `index.html` в браузере. Для разработки удобнее использовать расширение Live Server в VS Code.
3. Интернет нужен только для загрузки Google Fonts. Фотографии взяты из исходной концепт-доски и лежат локально в папке `assets/`.

## Файлы
- `index.html` — структура страницы и все секции сайта.
- `styles.css` — палитра, адаптивная сетка, карточки и мобильная версия.
- `script.js` — меню, поиск, фильтрация, сортировка, избранное, демонстрационная корзина, модальное окно заказа и уведомления.

## Что реализовано
- Главная, каталог, блок индивидуального заказа и «О кондитерской» как отдельные секции с навигацией.
- Адаптивная верстка для мобильных экранов.
- Поиск по товарам, фильтрация по категориям и сортировка по цене.
- Добавление товаров в демонстрационный заказ и избранное.
- Форма индивидуального заказа и подписки с демонстрационным подтверждением.
